# Historical Report Authority

Classification: `CURRENT_SUPPORTING` index; current phase/unit is owned only by [02_PHASE_LEDGER.md](../docs/reconstruction/02_PHASE_LEDGER.md).

All pre-existing Markdown reports in this directory are `HISTORICAL_RECORD`. Keep their original dates, claims, findings and scorecards as provenance; do not read CURRENT, READY, CLOSED, phase numbers, lint/build results, fixed key totals or release verdicts in their bodies as current reconstruction authority. Some records document competing or rejected designs. Current code and accepted decisions supersede them without rewriting their history.

`all_ts_files.txt` is a historical machine file-list artifact (`UNRELATED` to current reconstruction governance), not a current source manifest. JSON/catalog reports consumed by tooling/tests retain their explicit fixture/input role; they are not current locale-dictionary or product-release authority. Do not regenerate them as part of documentation convergence.

See [the exhaustive P0-U5 document inventory](../docs/reconstruction/DOCUMENTATION_AUTHORITY_REVIEW_P0_U5.md) for every audited path and disposition, and [the canonical decision/debt log](../docs/reconstruction/05_DECISION_AND_DEBT_LOG.md) for current accepted records. No historical report reopens accepted units or authorizes implementation.
