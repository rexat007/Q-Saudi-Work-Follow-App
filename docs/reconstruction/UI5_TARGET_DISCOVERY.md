- **CONVERGE:** account list/search/status, selected-person context and lifecycle/access decisions into one legible local workflow across existing USERS and SECURITY_ACCESS. The current command protocol has no UI-owned idempotency/receipt journal: **no automatic retry** or invented receipt. On an unknown outcome offer a deliberate existing read/reconciliation action; never assert that a timeout proves rollback. Do not retry a previously acknowledged first step when the second step/read fails.
- **RETIRE:** only hidden-section read work and duplicated account-selection ambiguity after regression proof. No deletion of capabilities, audit facts, role/project choices or supported identity linkage.
- **REBUILD:** none. Stop for owner review if the intended UX needs a new command, combined transaction, server idempotency/receipt API, broader queries, grant rules, source metadata contract or backend authority change.
